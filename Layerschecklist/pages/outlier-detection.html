Outlier Detection

Outliers can quietly wreck a model — skewing averages, distorting scaling, and misleading training. Knowing how to spot them is step one before any modeling happens.

Interview mindset:

For every method: What assumption does it make about the data? What kind of outlier does it catch — and what kind does it miss?

Z-Score Method

Measures how many standard deviations a point is from the mean. Points beyond a threshold (commonly 3) are flagged as outliers.

Interview check: Know this assumes roughly normal data — it can misfire on skewed distributions. 

from scipy import stats
import numpy as np

z_scores = np.abs(stats.zscore(data))
outliers = data[z_scores > 3]
IQR Method

Uses the interquartile range (spread of the middle 50% of data) to flag points far outside that range — more robust to skew than Z-score.

Interview check: Know the standard rule: anything beyond 1.5×IQR past Q1 or Q3 is an outlier. 

Q1 = data.quantile(0.25)
Q3 = data.quantile(0.75)
IQR = Q3 - Q1

outliers = data[(data < Q1 - 1.5*IQR) | (data > Q3 + 1.5*IQR)]
Visual Detection

Boxplots and scatterplots make outliers visually obvious before running any formal test.

Interview check: Be able to explain what the whiskers on a boxplot represent. 

import matplotlib.pyplot as plt

plt.boxplot(data)
plt.show()
Isolation Forest

A model-based approach — outliers are "easier to isolate" with fewer random splits than normal points. Works well in higher dimensions where boxplots and Z-scores don't apply.

Interview check: Know why this scales better to multi-feature data than the simpler statistical methods above. 

from sklearn.ensemble import IsolationForest

model = IsolationForest(contamination=0.05)
preds = model.fit_predict(X)
# -1 = outlier, 1 = normal

Outlier Detection Interview Questions You Should Be Able to Answer

  • What is the difference between the Z-score and IQR methods?
  • Why might Z-score misfire on skewed data?
  • What does the 1.5×IQR rule represent?
  • When would you use Isolation Forest instead of a statistical method?
  • Should outliers always be removed? When might you keep them?

The Standard You Want

You should be able to justify whether a flagged point is a genuine outlier, a data entry error, or a rare-but-real event — and explain why that distinction changes what you do next.

Detecting outliers is easy. Deciding what to do about them is the real skill.
